## What it does

- **Daily check-ins**: Track mood, stress, and progress feeling
- **Decision framework**: Structured questions to clarify tough choices
- **Trend visualization**: See how you're doing over time
- **History**: Review past logs and decisions

Data is stored locally in `~/.founder_compass.db`
